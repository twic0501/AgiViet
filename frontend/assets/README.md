# assets/ · Ảnh, biểu tượng, thư viện nhúng

- `products/`: ảnh mặt hàng (chọn theo mã sản phẩm, xem `ANH_SP` trong `thiet-ke/chung.js`).
- `icon-*.png`, `apple-touch-icon.png`, `logo.svg`: biểu tượng PWA (tạo bằng `scripts/make-icons.mjs`).
- Ảnh phong cảnh `*.jpg`: nguồn và giấy phép ghi trong `credits.json`.
- `trau/`: hình nhân vật trâu. `qr.js` (+`qr-LICENSE.txt`): tạo mã QR. `vendor/`: thư viện bên ngoài tải sẵn để chạy khi mất mạng.
