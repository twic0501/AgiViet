# quan-tri/ · Trang quản trị và bệ phóng tình huống thử

- `index.html` + `admin.js`: trang quản trị (ngân hàng ảo, tình huống, tra cứu).
- `launch.html`/`launch.js`, `chon-vai.*`, `play.*`: chọn vai và mở sẵn một tình huống nghiệp vụ để trình diễn.
- `case-engine.js`, `test-pages.js`, `demo-data.js`, `profiles.js`, `opponent.js`: dựng dữ liệu tình huống, đối thủ giả lập.

Chỉ dùng với backend môi trường thử (`AGV_MOI_TRUONG=thu`).
